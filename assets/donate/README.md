# 捐赠二维码资源 / Donate QR Assets

本目录用于存放 README 中引用的捐赠与关注二维码图片。

| 文件名 | 用途 | 建议尺寸 |
|--------|------|----------|
| `wechat-reward.png` | 微信赞赏码 | 300×300 px 或更高 |
| `wechat-official-account.png` | 微信公众号二维码 | 300×300 px 或更高 |

## 如何替换

1. 将真实二维码导出为 PNG（背景尽量留白，便于 GitHub / Gitee 渲染）。
2. 覆盖上述文件名，或修改 `README.md` / `README.en.md` 中的图片路径。
3. 提交前在本地预览 Markdown，确认相对路径 `assets/donate/...` 可正常显示。

当前仓库内为 **SVG 占位图**，发布前请替换为真实二维码。

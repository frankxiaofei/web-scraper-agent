# 捐赠二维码资源 / Donate QR Assets

本目录用于存放 README 中引用的捐赠与关注二维码图片。

| 文件名 | 用途 | 状态 |
|--------|------|------|
| `wechat-reward.png` | 微信赞赏码（occupyMars） | ✅ 已配置真实收款码 |
| `wechat-official-account.svg` | 微信公众号二维码 | SVG 占位图，待替换为 PNG |

## 如何替换公众号二维码

1. 将真实二维码导出为 PNG（背景尽量留白，便于 GitHub / Gitee 渲染）。
2. 保存为 `wechat-official-account.png`，并更新 `README.md` / `README.en.md` 中的图片路径。
3. 提交前在本地预览 Markdown，确认相对路径 `assets/donate/...` 可正常显示。

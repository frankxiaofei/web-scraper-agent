语法说明（L2 爬取规则 v1）

规则分层

  • L1 — sites.yaml：站点启用、adapter、limits 覆盖
  • L2 — crawl_rules/*.yaml：声明式规则（本页编辑）
  • L3 — AI 对话生成草稿，人工确认后落盘为 L2
  • L4 — Agent 录制步骤序列，可导出为 L2

顶层字段

  • version — 规则版本，当前为 1
  • site_id — 站点 ID，须与文件名一致
  • entry_url — 爬取起始 URL（可与 sites.yaml 不同）
  • entry_steps — 从入口到列表页的导航步骤
  • list_page — 列表提取策略与选择器 / API
  • pagination — 翻页方式与上限
  • detail — 是否抓取详情正文
  • limits — 页数、条数、深度、限速

entry_steps 动作

  • navigate — 打开 url
  • click_text — 按可见文本点击（如「采购公告」「更多」）
  • click_selector — 按 CSS 选择器点击
  • wait — 等待 selector 出现
  • wait_network — 等待匹配 url_pattern 的 XHR

list_page

  • strategy — dom | api | dom_after_ajax
  • container / item / title / link / date — DOM 选择器
  • api 块 — REST 地址、params、page_param、fields 字段映射

pagination.type

  • ajax_param — 直接请求 API 递增页码（zycg 推荐）
  • next_button — 点击「下一页」按钮
  • page_number — 遍历页码链接
  • load_more — 点击「加载更多」

limits 约束

  • max_pages — 最多翻页数（默认 20）
  • max_items — 最多采集条数（默认 100）
  • max_depth — 链接递归深度（默认 2）
  • rate_limit_seconds — 请求间隔秒数

L1 sites.yaml 可覆盖 max_items、fetch_detail 等。

zycg 示例片段

entry_url: https://www.zycg.gov.cn/.../cggg/index.html
list_page:
  strategy: dom_after_ajax
  container: "#noticeShow"
  api:
    url: .../selectInfoMore.do
    page_param: currPage
pagination:
  type: ajax_param
  page_param: currPage
  max_pages: 20

客户端配置规则

使用桌面客户端内嵌 Chrome 录制站点操作，生成 crawl_rules 工作流

← 站点列表

1. 启动 Web UI

确保后端 API 已运行（默认 http://127.0.0.1:8090）。

python scripts/run_web_ui.py --port 8090

2. 启动桌面客户端

在项目根目录执行：

bash scripts/start_rule_config_client.sh{% if site_id %} {{ site_id }}{% endif %}

首次运行会自动 npm install（在 client/ 目录）。

3. 录制与保存

  1. 选择站点，打开入口 URL
  2. 点击「开始录制」，在左侧浏览器中操作
  3. 确认列表页弹窗（如有）
  4. 停止录制 → 编译工作流 → 保存规则 → 试跑
